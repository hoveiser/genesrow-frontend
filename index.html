🎯 What is GenEscrow?

GenEscrow is a decentralized escrow smart contract with real payable custody that uses AI validators to adjudicate disputes. The deliverable evidence is cryptographically sealed on-chain at delivery time and verified at adjudication time.

🔏 Sealed Evidence Binding (v1.1.x):

1. Freelancer submits deliverable URL at delivery

2. Contract fetches the URL, extracts visible text, computes sha256 hash, stores it on-chain

3. At adjudication, URL is fetched again and hash is verified

4. If hash matches → AI judges the content

5. If hash differs → EVIDENCE_MISMATCH verdict, automatic refund; live mutated content is never trusted

✅ How it works:

1. Client creates escrow with agreed acceptance criteria and deposits real GEN (payable)

2. Freelancer delivers work (URL sealed with hash)

3. Client approves → funds released via on-chain transfer

4. Client silent? → timeout_release frees funds to freelancer after the window

5. Dispute? → AI validators fetch the deliverable's visible text and vote APPROVED / REFUNDED

6. Losing party may appeal once → second AI round is final → finalize pays out

💡 Technical Highlights

  • Built on GenLayer Bradbury testnet with real AI validators (Mistral, Gemini, Kimi, GPT-OSS)
  • Real payable custody via @gl.public.write.payable
  • Sealed evidence binding: sha256 hash of visible text stored at delivery, verified at adjudication
  • On-chain transfers via gl_call_generic({'EthSend': ...})
  • Consensus-safe time via gl.message_raw["datetime"] for timeouts & appeal windows
  • AI adjudication on visible text (HTML/CSS stripped) via gl.nondet.exec_prompt
  • Consensus via gl.eq_principle.strict_eq on canonical binary verdicts
  • Immutable freelancer-submitted evidence (URL + sealed hash)
  • Retry (3 attempts) + safety windows — no automatic payout on transient failures
  • One-shot appeal with a final AI round
  • Authorization checks on every write method
