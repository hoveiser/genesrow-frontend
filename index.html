🎯 What is GenEscrow?

GenEscrow is a decentralized escrow smart contract with real payable custody that uses AI validators to adjudicate disputes. Deliverables must be authenticated immutable artifacts (GitHub commits at full SHA, IPFS CIDs, or Arweave), evidence is cryptographically sealed on-chain at delivery, and AI verdicts include on-chain reasoning.

🔏 Authenticated Artifacts (v1.2.0):

1. Only immutable artifacts accepted: GitHub raw/blob/commit at full 40-char SHA, IPFS CID, Arweave

2. Client binds authenticity at creation: expected_owner / expected_repo / expected_path

3. Contract extracts owner/repo/path from the URL at delivery and enforces exact match

4. HTTP error pages (4xx/5xx) and empty content rejected at seal time — no seal on 404s

5. Sealed sha256 of visible text re-verified at adjudication; mutated content → EVIDENCE_MISMATCH refund

🧠 Leader/Validator Consensus + On-Chain Reasoning (v1.2.0):

1. Leader fetches artifact, calls AI, returns {verdict, reasoning}

2. Validators independently re-run the audit and compare only the verdict (Partial Field Matching per GenLayer docs)

3. Consensus via gl.vm.run_nondet_unsafe(leader_fn, validator_fn)

4. AI explanation stored on-chain in ai_reasoning — stewards can verify why the AI voted

5. Structural index of all def/class declarations prevents truncation false negatives on code artifacts

✅ How it works:

1. Client creates escrow with acceptance criteria + expected repo/path and deposits real GEN (payable)

2. Freelancer delivers an authenticated artifact (URL sealed with sha256)

3. Client approves → funds released via on-chain transfer

4. Client silent? → timeout_release frees funds to freelancer after the window

5. Dispute? → AI validators fetch the artifact and vote APPROVED / REFUNDED with reasoning

6. Losing party may appeal once → second AI round is final → finalize pays out

💡 Technical Highlights

  • Built on GenLayer Bradbury testnet with real AI validators (Mistral, Gemini, Claude, GPT)
  • Real payable custody via @gl.public.write.payable
  • Authenticated immutable artifacts: GitHub SHA / IPFS / Arweave whitelist only
  • Authenticity binding: expected owner/repo/path enforced at delivery
  • HTTP error rejection: 4xx/5xx and empty content never sealed
  • Sealed evidence binding: sha256 of visible text stored at delivery, verified at adjudication
  • Prompt injection protection: sanitize + <data> tags + structured JSON verdicts
  • Leader/validator consensus: gl.vm.run_nondet_unsafe with Partial Field Matching
  • On-chain AI reasoning: verdict consensus-verified, explanation stored for auditability
  • Structural index: def/class declarations prevent truncation false negatives
  • On-chain transfers via gl_call_generic({'EthSend': ...})
  • Consensus-safe time via gl.message_raw["datetime"] for timeouts & appeal windows
  • Retry (3 attempts) + safety windows — no automatic payout on transient failures
  • One-shot appeal with a final AI round
  • Authorization checks on every write method
