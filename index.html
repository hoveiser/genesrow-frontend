🎯 What is GenEscrow?

GenEscrow is a decentralized escrow smart contract with real payable custody that uses AI validators to adjudicate disputes between freelancers and clients. No human middlemen, no delays, no trust required.

✅ How it works:

1. Client creates escrow with agreed acceptance criteria and deposits real GEN (payable)

2. Freelancer delivers work (URL + evidence hash, immutable)

3. Client approves → funds released via on-chain transfer

4. Client silent? → timeout_release frees funds to freelancer after the window

5. Dispute? → AI validators fetch the deliverable's visible text and vote APPROVED / REFUNDED

6. Losing party may appeal once → second AI round is final → finalize pays out

🚀 How to Use

1. Go to GenLayer Studio

2. Paste the code from contract.py and deploy your own instance

3. Call create_escrow(freelancer, description, criteria, approve_window, appeal_window) with GEN value

4. Test flows: mark_delivered → approve | dispute → resolve → appeal → finalize | timeout_release

5. Watch AI validators adjudicate in real-time!

💡 Technical Highlights

  • Built on GenLayer Bradbury testnet with real AI validators (Mistral, Gemini, Kimi)
  • Real payable custody via @gl.public.write.payable
  • On-chain transfers via gl_call_generic({'EthSend': ...})
  • Consensus-safe time via gl.message_raw["datetime"] for timeouts & appeal windows
  • AI adjudication on visible text (HTML/CSS stripped) via gl.nondet.exec_prompt
  • Consensus via gl.eq_principle.strict_eq on canonical binary verdicts
  • Immutable freelancer-submitted evidence (URL + hash)
  • Retry (3 attempts) + safety windows — no automatic payout on transient failures
  • One-shot appeal with a final AI round
  • Authorization checks on every write method
